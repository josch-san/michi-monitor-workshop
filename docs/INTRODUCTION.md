# Introducción - Michi Monitor

Los michis pasan mucho tiempo solos en casa y desde hace mucho tiempo nos preguntamos... ¿Qué hacen los michis mientras no estamos?

![image](images/cat_climbing_curtains.gif)

## Solución

Michi Monitor usa alta tecnologia para saber que estan haciendo los michis mientras trabajas para comprar cosas importantes como el alimento balanceado, o las piedritas de baño. Por medio de reconocimiento de imagenes en una camara se hace tracking de los michis.
